# 初赛交付与复现

参赛项目：面向短视频创作复盘的多智能体编排与验证平台。

## 环境

Python 3.9+。完整视频流程需要 ffmpeg 与 ffprobe。原生前端无需构建，Node.js 仅用于前端测试。项目只监听本机回环地址。

## 无 API 演示

在解压目录执行 `python offline_demo.py`，或双击 `启动离线演示.cmd`。脚本创建隔离的合成回放案例并打开复核页面。可查看证据、比较初稿与候选稿、保存人工复核。此模式不调用模型，不展示真实质量提升；不会改动个人工作台已有任务。再次打开保留此前演示记录。

## 真实运行

1. 配置 DASHSCOPE_API_KEY、DASHSCOPE_BASE_URL 和支持图片的 DASHSCOPE_MODEL，密钥不写入源码。
2. 运行 `python launch_review.py`，使用启动器输出的动态端口。
3. 登记视频及可选字幕，同页上传该作品的数据截图，核对作品身份、发布时间和截图统计时间。
4. 冻结目标与预算后启动。智能规划占用一次模型调用；规划失败不会伪装成成功，规则执行可在启动前明确选择。
5. 在日志中检查规划、工具分支、分析、验证及反馈路径。需要修正时须预留修正加复验两次预算；缺证直接停止。
6. 人工确认后挑选 1～2 条用于下一条作品，不重发当前作品。下一条使用同目标、同口径与同观察窗口比较。

## 可执行验证

`python -m unittest discover -s tests -q`

`node --test tests/*.cjs`

测试使用合成数据且不调用真实服务，验证结构、数据约束、调度和界面逻辑，不能代替模型质量评估。真实质量结果见提交方案书；原始人工标注仅留本机。

## 日志

HTTP 日志在 reports/review-server，工作流在 reports/workflows，离线演示在 reports/offline-demo。不要对外发送密钥、整份本地日志或私人素材。源码压缩包排除运行产物、个人截图、样本和配置。

## 当前边界

已实现受约束模型规划、依赖就绪调度、工具并行、验证驱动有界修正与人工复核。尚未实现通用动态 Agent 发现、子工作流嵌套、向量知识库检索；智能规划最新真实网络验收未成功。离线演示和单元测试不能替代这一验收。2026-11-11 的提示词改进尚无新增真实质量对照。
