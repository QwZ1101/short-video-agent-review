# 网页登记与启动

双击 `启动复核工作台.cmd`，在首页选择“运行任务”，或打开启动器返回地址的 `/start` 页面。

1. 选择已有样本，或登记视频完整路径、目标、受众和观众基础，可选填 SRT 字幕。
2. 选择本轮预算：2 次为分析＋验证，4 / 6 次分别允许最多 1 / 2 轮追加返修。
3. 点击“检查材料并预览计划”。此步骤不调用模型，检查本地材料、FFmpeg、FFprobe 和服务环境配置，显示执行与跳过的步骤。
4. 阅读材料发送与用量提示后点击启动。页面显示阶段、已尝试调用数、失败原因和人工复核入口。

网页仅登记基础材料；额外截图、配套说明和平台指标仍在本地样本 JSON 中维护。登记检查可读性，不保证视频可解码或素材内容正确。

## 预算与重复请求

计划绑定样本配置 SHA256、材料大小和修改时间，保存绝对路径快照。启动前发现变化就拒绝执行，需重新预览。这不是大视频内容的完整哈希验证；模型输入图片仍由现有证据流程记录 SHA256。

启动接口只接受已预览的任务编号，不接受新的预算、模型、脚本路径或命令。每个计划只有一次启动机会；浏览器超时、刷新或重复发送不会再次创建同一任务。失败后再次尝试必须显式准备新计划，原记录保留。

网页任务共用一个跨进程运行槽，避免不同标签页同时启动。限制只覆盖网页入口；不要同时手动启动命令行流程，否则仍可能发生额外用量。阶段预算是本轮上限，不代表会使用全部次数，也不等于服务端计费次数。

后台通过固定 Python 程序启动，参数逐项传递，不经过 shell。Windows 使用隐藏独立进程，关闭浏览器或重启网页服务不终止已经启动的工作进程。进程意外退出时保留占用并提示排查，避免尚有模型子进程时再次启动。不能凭超时直接删除占用记录；须先核对该任务工作进程及子进程全部退出，再由维护者处理。

## 环境与边界

启动工作台前配置 `DASHSCOPE_API_KEY`、阿里云官方 HTTPS `DASHSCOPE_BASE_URL`，可选 `DASHSCOPE_MODEL`。工作进程继承服务启动时的环境；改变环境变量后须重启工作台。页面不接收、返回或保存密钥。环境检查不验证模型权限、余额或实际网络可达性。

服务只监听 `127.0.0.1`，复用 Host、Origin 与令牌校验；静态路径仍受白名单限制。登记页明确提供的本地视频/字幕路径用于复盘，不执行素材和源码包。启动会将所选图片、字幕和配套内容发送至配置服务。

## 记录与排查

- `reports/web-jobs/job-.../` 保存计划、配置快照、启动和工作进程的独占标记、PID、状态、启动日志及事件摘要。
- `reports/workflows/run-web-.../` 保存完整工作流、阶段日志与模型结果，可由网页进入日志或人工复核页。
- 启动入口的 HTTP 请求纳入轮转日志，不记录正文、查询参数或凭据。每个任务仅写有限生命周期事件；历史档案不自动删除。
- 模型连接错误在页面展示已有错误记录中的脱敏原因。新分析失败会更新阶段元数据，中断回答单独保存，不能当作有效结果。

记录由 Git 忽略，只留在本机。程序测试覆盖成功交接和异常路径，但不代表实时模型服务可用。真实运行是否完成以各轮 `workflow.json` 为准。
